# KB Photo Tool
Kalinga Bani ke liye free Resize + Compress web app. Sab kuch browser me hota hai, koi server nahi.

## GitHub Pages par chalane ke steps
1. github.com par naya repo banao (naam: `kb-photo-tool`, Public).
2. "Add file > Upload files" se is folder ki saari files daalo (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png) aur Commit karo.
3. Repo me Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `(root)` > Save.
4. 1-2 minute baad link milega: `https://<tumhara-username>.github.io/kb-photo-tool/`
5. Phone me Chrome me link kholo > menu (3 dots) > "Add to Home screen / Install app".
